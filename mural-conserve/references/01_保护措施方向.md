# 病害保护措施方向参考

本表用于把 `mural-diagnose` 的判读转为“这幅壁画接下来可以考虑哪些保护方向”。它写到措施方向、先决条件和风险为止。材料选择、配比、浓度、工艺参数、施工顺序和是否实施，由具备资质的文物保护专业人员经现场调查、材料分析和小范围试验后决定，并按项目审批程序执行。

## 一、制定建议时遵循的原则

| 原则 | 写建议时的含义 |
|---|---|
| 先调查、后干预 | 影像判读只到表观现象。涉及实体处理的建议，先写清需要哪些调查（层位、空鼓范围、盐分、含水、环境、既往修复）才能决定是否处理。 |
| 预防性保护优先 | 能通过控制环境、管理参观、防尘防水、定期监测降低风险的，优先于直接处理画面。 |
| 最小干预 | 只处理影响稳定或安全的部位，范围以调查结果为准。不为“好看”扩大处理范围。 |
| 兼容、可再处理 | 所用材料与原材料在物理化学性能上兼容，不妨碍今后再次处理。具体材料由试验确定。 |
| 保留真实性 | 不重绘、不臆补画面内容。缺失部位的补全只在数字层面进行，并明确标识推测成分。 |
| 全程记录 | 处理前、中、后都需记录影像、位置、材料和人员，便于追溯和监测效果。 |

## 二、建议的阶段划分（`stage` 字段）

| 阶段 | 典型内容 | 一般由谁执行或决定 |
|---|---|---|
| 调查诊断 | 补拍（正光与侧光、带比例尺和色卡）、查阅档案、现场观察、无损检测、取样分析、环境监测布点 | 采集人员、文保研究人员 |
| 预防性保护 | 温湿度与通风控制、防水排水、控光、防尘、控制参观量、防止触碰和生物入侵 | 管理单位与文保人员 |
| 应急稳定 | 对有坠落或继续剥落风险的部位做临时防护或临时支护 | 文保专业人员现场判断 |
| 修复处理 | 回贴、灌浆、脱盐、清洗、加固、填补边缘等实体措施的方向 | 文保专业人员，经试验和审批 |
| 监测 | 定点定机位复拍、裂缝或空鼓范围复测、环境数据长期记录，并写明触发复查的条件 | 管理单位与文保人员 |

## 三、病害与保护措施方向对照

| 病害（判读） | 先决调查 | 可考虑的措施方向 | 主要风险与注意 |
|---|---|---|---|
| 起甲、泡状起甲 | 侧光近摄确认翘起范围和层位；判断是否伴随酥碱或盐分；了解环境湿度变化 | 预防性控制湿度波动；由专业人员对翘起颜料层做回贴加固；处理前对松动片做临时保护 | 回贴材料不兼容会造成眩光、变色或新的应力；在含盐或潮湿部位只回贴不处理病因，问题容易复发 |
| 酥碱、酥碱起甲 | 盐分种类与含量、含水状况、环境温湿度记录、病害分布与水源关系 | 首先查明并控制水分和湿度来源；由专业人员评估脱盐（如敷贴吸附类方法）与地仗加固的必要性；配合环境控制 | 盐分在湿度变化中反复结晶会持续破坏；处理不当可能把盐带到表面或引起新的剥落；单张照片不能确认酥碱 |
| 空鼓、严重空鼓 | 现场确定空鼓范围（莫高窟 85 窟以轻敲听声为主）、空鼓深度、边缘开裂和变形情况 | 严重空鼓先做应急支护或临时防护；由专业人员评估灌浆加固，必要时辅以锚固；含盐时需与脱盐方案统筹 | 存在整块坠落风险；灌浆材料、重量和含水会影响稳定性并可能带动盐分迁移，须经试验确定 |
| 裂缝 | 区分绘前裂缝与后期裂缝；判断是否贯穿地仗，是否与结构或支撑体变形有关；建立裂缝宽度基线 | 稳定的裂缝以监测为主；发展中的裂缝先查结构原因；由专业人员评估边缘加固和填缝 | 把绘前裂缝或线描误判为损伤；只填缝不查结构会掩盖问题 |
| 画层、粉层、地仗脱落 | 确认露出面属于哪一层；检查缺损边缘是否松动；查旧修复档案 | 对松动边缘做加固，防止脱落范围扩大；必要时由专业人员做边缘填补（低于画面、不补画）；画面缺失部分只做数字示意 | 在实物上补绘会损害真实性；填补材料与原材料不兼容会产生新的边界损伤 |
| 点状脱落、火山口状脱落 | 高倍近摄；取样分析中心硬核成分；了解分布与墙基或湿度的关系 | 控制环境湿度，由专业人员评估局部加固 | 与霉斑、颜料颗粒和噪点混淆；病因不明时处理效果难以保持 |
| 烟熏、积尘、表面沉积、昆虫排泄物 | 确认沉积物与画层的关系、画层是否稳定；成分分析；查看清洗是否会带走颜料 | 先防尘、防虫和管理火源；由专业人员通过小范围试验确定是否清洗以及清洗程度 | 清洗过度会损失颜料或改变色调；画层不稳定时不宜清洗 |
| 霉变、微生物 | 确认是否仍有活体；微生物鉴定；含水和通风状况 | 首先降低湿度、改善通风；由专业人员评估是否需要针对性处理 | 杀菌或清除方法可能伤害颜料；不改善环境容易复发 |
| 变色、褪色 | 校色影像对照；同类纹样对照；颜料分析；光照记录 | 控制光照和湿度，减缓进一步变化；变色本身一般以记录和监测为主；原色只在数字层面推测展示 | 把成像色偏误判为变色；试图在实物上恢复原色会损害真实性 |
| 机械损伤、刻划涂写 | 区分原有题记、起稿线与后期损伤；判断是否有历史价值 | 加强防护和参观管理；由专业人员评估是否需要处理后期涂写 | 有历史价值的题记不应清除；清除涂写可能伤及下层颜料 |
| 旧修复（旧填补、旧补色、旧加固材料） | 查修复档案；判断旧材料是否老化并对原画产生危害 | 状态稳定时保留并记录；有危害时由专业人员评估是否局部去除或替换 | 去除旧修复本身有风险，可能连带损伤原画层 |

## 四、整体保护思路怎样写（`overall_strategy`）

用一段话说明：这幅壁画当前影像所见的主要风险是什么，哪些病害可能有共同成因（例如同时出现起甲、点状脱落并向墙基加重，提示需优先调查湿度和盐分），建议按什么顺序推进（一般是先补证调查与应急稳定，再预防性保护，再按调查结果决定修复处理，全程监测）。要写明这只是基于影像的初步思路。

## 五、数字展示与公众传播（附加项）

用户需要时可写。数字复原须基于已核实的观察和同类纹样，标注推测部分及其依据，保留原图与出处，说明与实物现状的区别。公众传播材料应引用已复核的判断，不夸大病害或渲染“即将消失”，并考虑影像授权、对象安全（如不公开敏感位置）和传播语境。
