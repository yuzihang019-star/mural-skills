# ① 画面病害识别分析

一个案例对应一张有明确范围的基准照片。本 skill 分两个阶段在同一个案例文件夹内完成：第一阶段初筛，尽量不漏地找出候选；第二阶段复核，逐条核对证据、排除误报、收窄判读。完成后把 `02_review.json` 交给 `mural-conserve`。

适用于馆藏档案、例行巡查、修复前影像记录和数字化质检。多张视角或不同日期的照片分别建案例，比较时写明对应关系和拍摄条件。

## 第一阶段 · 初筛

1. 记录照片来源和用户提供的对象标识、拍摄时间、评估目的与范围。区分已知信息和未提供的信息。优先使用原始图像。
2. 运行 `python <skill>/scripts/screen.py <图像> <案例文件夹> --no-hints`。可用 `--source` 记录来源，`--team` 记录机构或项目。脚本保留原图，生成坐标整图、分块放大图和增强图。已有案例必须继续使用同一张基准照片。
3. 按 [看图步骤](references/02_看图步骤.md) 确认可评范围，定位需要记录的局部。在逐条判读前查阅 [病害百科](references/01_病害百科.md) 的证据等级与相关形态条目。石窟类影像同时查阅该页的七类重点鉴别和莫高窟第 85 窟术语对照，结合对象材料、技法和背景判断。局部坐标以基准照片像素为准。
4. 按 [输出格式](references/03_输出格式.md) 填写 `01_findings.json`。先写照片能看清的位置、形状、范围和受影响的图纹，再写暂定类型和待核查的问题。
5. 运行 `python <skill>/scripts/check_findings.py <案例文件夹>`，生成 `01_findings.png`、`01_crops.png` 和 `01_candidates.json`。

## 第二阶段 · 逐条复核

按 [复核步骤](references/04_复核步骤.md) 执行。

```bash
python <skill>/scripts/init_review.py <案例文件夹> --model "<本次复核所用模型>"
python <skill>/scripts/view.py <案例文件夹> whole
python <skill>/scripts/view.py <案例文件夹> box x,y,w,h [x,y,w,h ...]
```

1. 对每个初筛候选给出 `确认`、`存疑` 或 `否决`，写明依据和仍成立的其他解释。
2. 把需要保留的现象整理成 `regions`，标签用 `A`、`B` … `Z`、`AA`。可新增初筛遗漏的区域，也可合并相邻同类表现。保留原图定位框。需要标出点、线或真实可辨的外缘时，按复核步骤填写可选的 `map_marks`。
3. 每个保留区域填写 `diagnosis`，分别写最可能的判断、用于区分解释的照片细节、仍成立的替代解释，以及能区分它们的人工核查方法。只能辨认外观时，直接说明能看清什么、还差什么证据。
4. 在 `overall_observation` 写实际可评范围、总体状况和限制。
5. 运行 `python <skill>/scripts/check_review.py <案例文件夹>`，生成 `02_regions.png`。

## 报告语言

给读者的每处记录依次呈现「可见现象」「病害判断」「人工核查方法」「保护措施」。本阶段写前三项，第四项由 `mural-conserve` 根据同一编号补写。JSON 仍沿用原字段，显示名称与字段的对应关系见 [复核步骤](references/04_复核步骤.md)。

- 可见现象用容易在图上指出的词。先写部位，再写形状、颜色、边缘及它与画中线条的关系。可写「右眉上有一块不规则黄褐斑，斑处眉线中断」。把「露底」「凹陷」「翘起」留给确实可辨的形态或已有现场证据。
- 病害判断优先使用适用的专业术语。可辨认片状缺失、但具体层位待查时，可写「疑似局部表层脱落，涉及的层位待核查」。只有一块颜色异常时，可写「褐色斑块，性质待查」。可以在同一处指出什么支持这一判断、还可能是什么。
- 人工核查方法写清要查的部位、采用的方法，以及哪种观察结果支持哪个判断。用「用两侧斜光近拍，看斑缘有无凹下的台阶或高出画面的附着物」这样的完整句。需要盐分鉴别、隐蔽层间检查或取样时，交给负责该对象的文保专业人员选择方法。
- 照片依据在报告中显示为「较清楚」「有限」「较弱」。它表示照片对本条病害判断的支持程度。另列核查优先级，依据位置价值、可能影响和核查的必要性安排。两者都不能用于给病害严重程度分级。

## 判断边界

- 单张照片中的白色小点可以记为「浅白色点簇」。只有能看出颗粒或表面覆层时，才写「白色颗粒状附着物」。颜料、粉尘、盐类沉积或局部缺失需要相应证据支持。盐成分、病害活动性、隐蔽的层间状态和变化速度需要照片以外的调查。
- 细线可记为「线状痕迹」。若看见线贯穿图纹且呈开口或分叉，并且足以和画中的笔线等解释区分，可写「疑似裂隙」并列出核查办法。沿笔线和数字拼接边界分布的线，须先检查其来源。
- 空结果需要说明原因。清晰且已检查的范围可写“在该范围内未见明显异常”；失焦、反光或覆盖不足则写“影像不足以判断”，指出需要补拍的区域和条件。
- 可用 `scripts/look.py <案例> zoom x,y,w,h ...` 查看源图局部。增强图用于定位，颜色、纹理和边界的判断回到原始照片。
- 按项目需要启用可选的 MuralDH 离线模型，在准备阶段省略 `--no-hints`。它只辅助寻找脱落或露底形态，适用性需结合材料域判断。只有根据提示实际回看了图像，才将 `small_model_hints_used` 标为 `true`。

## 交付

简要说明照片覆盖的范围、保留区域数量、各区的病害判断与核查优先级，以及主要排除依据和缺少的证据。附上 `02_regions.png`，保留原图上的定位框或点、线、轮廓标记。框只用于回到原图位置。需要保护报告和复核单时，分别由 `mural-conserve` 生成 `03_report.pdf`，由 `mural-review-pdf` 生成 `04_review_form.pdf`。
