# 基准影像检查方法

## 1. 确定评估范围

查看整图、输入说明和原始尺寸。记录能覆盖的表面、看不到的位置，以及反光、阴影、透视变形、失焦、压缩、裁切或拼接疑点对哪些判断有影响。区分用户提供的基准图、未经拼接的拍摄原片和临摹或数字复原图。局部照片只代表该局部。没有可靠比例尺时，用原图像素定位，物理尺寸标为未知。

## 2. 查看分块和需要复看的局部

用 `01a_whole.png` 建立位置关系，用 `01b_tiles.png` 对照分块。在靠近边界或细节不清时，用下列命令从原图提取局部。

```bash
python <skill>/scripts/look.py <案例> zoom x,y,w,h x,y,w,h
```

按实际情况补看必要的原尺寸细节。用 `tiles_checked` 记录已查的块。用 `tiles_excluded` 记录未查的分块及原因，如超出项目范围、遮挡或严重失焦。部分区域受限时同时描述块内受限位置。增强图或小模型提示用于定位，证据回原图核对。

## 3. 先写现象，再写解释

| 观察到的形态 | 检查的区别 |
|---|---|
| 不规则浅色区、原有线条中断 | 比较原有留白、后期填补、层面缺失，查看同类图案和边缘连续性。 |
| 贯穿多种图案的细线或网状细纹 | 比较绘画线描、接缝、表面裂纹和压缩伪影。影像可支持线状形态，深度和活动性需补证。 |
| 边缘亮暗交替、局部片状阴影 | 比较起翘、笔触、颗粒纹理和拍摄光向。条件允许时使用近摄和侧光资料。 |
| 彩色斑块、浅白点簇、滴流状痕迹 | 先记录颜色、边界和分布。观察是否有可辨颗粒、台阶或覆盖关系，再选本处有依据的替代解释。 |
| 局部颜色或明暗不均 | 同时检查光照、曝光、色彩校正、老照片可比性和原有设色。 |
| 刻划、文字、疑似旧修 | 记录形态和相互覆盖关系。交由档案和材料证据区分创作、历史叠加、后期修补和损伤。 |

记录证据强弱和反例。仍有合理替代解释但值得核查的，留在候选中并标低或中置信度。已有足够证据支持原有纹样或成像伪影时，在 `rejected` 中记录理由。把仅有拍摄缺陷且没有可定位现象的区域记入覆盖说明。

## 4. 检查结果是否支持后续复核

每条候选都应能回到原图核对。只写置信度允许的解释，并说明增加何种资料能区分。若同一现象跨块，合并重复条目。若一个框包含多种现象，按需要拆分。无候选时用 `overall.condition_reason` 说明已查范围及限制。最后运行 `check_findings.py`。
