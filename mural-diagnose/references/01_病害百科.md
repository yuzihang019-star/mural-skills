# 彩绘表面影像判读参考

适用于矿物或有机颜料壁画、建筑装饰彩绘和现代壁画的影像记录。先辨认可见形态，再结合对象的支撑、底层、涂层和既有修补资料解释。墙体彩绘、木构彩绘和现代涂层的层次可能不同，不能仅凭浅色、粗糙或某种纹理指定暴露层。

## 照片的证据等级

| 级别 | 影像能支持什么 |
|---|---|
| A | 清晰图像能支持形态描述，如线状中断、片状缺失外观或局部覆盖物。直接写可见现象，疑似类型须结合上下文。 |
| B | 有形态线索，但类型或层位存在重要替代解释。置信度最高为中，说明需要什么补充资料。 |
| C | 现有照片很难验证解释，例如层间分离、表面粉化、盐的成分或微生物活动。置信度为低，只记录可见迹象和核查需求。 |

同一位置可以有清楚的 A 级形态和待核查的 C 级解释。初筛记录的 `photo_grade` 和 `confidence` 对应 `type` 的解释层级。多角度照片、连续监测记录或专业检查的证据应标来源，单独说明其支持的结论。

## 常见形态及替代解释

| 形态 | 可考虑的解释 | 容易混淆的现象和可用证据 |
|---|---|---|
| 不规则片状或点状浅色区，线条在边界中断 | 表层缺失，局部露底 | 原画留白、装饰性点纹、旧修补或压缩噪点。比较纹样连续性、近摄和不同光向。 |
| 深色凹陷外观，边缘显出层状或台阶 | 更深层缺失或旧修补边界 | 深色笔触、投影和不平整的填补。仅靠色调无法区分颜料层、地仗层及支撑体。 |
| 单条深纹、跨图案线状中断或网状细纹 | 疑似裂隙、表面细裂纹 | 线描、接缝、折痕、规则网格和锐化伪影。比较交叉位置、图案连续性、侧光和周边载体。 |
| 片状突起或边缘亮暗交替 | 疑似起翘、起甲或旧修边缘 | 厚笔触、颗粒、压纹、自然起伏和拍摄反光。优先核查侧光及近摄；弱线索只记外观。 |
| 白色颗粒、绒状物或粉状外观 | 表面沉积、粉尘、颜料或可能的盐析 | 颜料配色、材质颗粒、反光、涂料飞溅和表面覆盖物。成分、来源及表面是否粉化需要专业核查。 |
| 黑褐斑、流痕状边界或成簇斑点 | 表面覆盖或变色，可能与污染、潮湿或生物因素有关 | 原有晕染、照明色偏、颜料本身变色、积尘和缺失。需要对比历史影像、环境记录或专业检查。 |
| 色彩或明暗不均 | 可见色差，待区分原有设色、成像或色彩变化 | 白平衡、曝光、阴影、拍摄方向和处理流程变化。监测需要可比的光照、角度、色彩校正和记录日期。 |
| 方向明显的刻线，文字或有边界的补色 | 划痕、涂写、原有刻线、题记或历史修补 | 材料、覆盖关系、历史资料和相关背景。观察记录先说明形态，是否构成损伤需结合对象价值。 |

对层间分离、成分、活动性或处理方案有疑问时，将能支持的影像记录交给具备相应经验的人员。检查方法由项目的对象状态、权限和专业要求决定。

## 石窟壁画七类重点鉴别

《石窟壁画的主要病害》提供了七类对象的基本形态、层间关系和可能诱因。以下按照片判读顺序整理。具体诊断术语优先使用项目采用的现行标准；需要细分层位时，对照下一节莫高窟第 85 窟的图解术语，尺寸阈值及机理须按实际对象验证。

| 病害 | 图像鉴别要点 | 容易混淆与需要的补证 |
|---|---|---|
| 起甲 | 局部薄片的边缘相对邻近表面翘起、卷曲或呈鳞片状，常在侧光下有规律的亮暗边。可能只涉及颜料层，也可能包含底色层或重层壁画界面。 | 将起翘与颜料缺失、厚笔触、旧填补区分。双向侧光近摄核对边缘高低，层位结合现有断面或档案。闭合圆顶形隆起另记疑似起泡。 |
| 酥碱 | 可记录连片或点状的粗糙、起砂样或粉末样外观。有水分和相对湿度变化时，可溶盐迁移、溶解、结晶及相关应力可损伤地仗内聚力。 | 白色沉积、可见色差、粉化外观分别记录，均有其他成因。判断酥碱需要地仗状态、盐分和环境资料。单图对酥碱仅提供低置信度线索。 |
| 空鼓 | 关注局部隆起、边界开裂、形变等线索，记录疑似失黏界面。地仗与支撑体之间的隐蔽分离也可能看不到明显表征。 | 区分闭合起泡、表面起甲、重层分离和深层空鼓。由文保人员核对层次和适用的现场无损证据。照片只能描述可见形变。 |
| 大面积脱落 | 先描记缺失范围和剩余彩绘的中断，比较缺损边的台阶、颗粒纹理和露出面的连续性。 | 面积大小和色深不足以判层。将疑似颜料层缺失、底色层缺失及可能涉及地仗的缺损分别记录，需实物边缘、可靠比例尺或断面档案确认。 |
| 烟熏 | 先描述灰黑或棕黑沉积样外观、覆盖纹样的关系，以及是否有空间梯度。 | 对照原画深色、颜料变色、积尘、水迹和生物斑。需结合建筑使用和火源历史、沉积分布及成分证据。是否仍受影响需另外核查。 |
| 霉变 | 先记录成簇斑点、丝状或绒状外观和分布。 | 颜料颗粒、尘垢、残留色素、旧菌体均可相似。材料性质及是否仍有菌体活动应由专业调查分别确认。 |
| 变色 | 分开记录色相变化、颜色减弱和色层缺失。单图优先描述现有色差及其是否沿材质或设色边界。 | 对照校色影像、原有配色、覆盖物及照明条件。铅丹等材料在部分样品中有变色证据，本案颜料种类及转化机制依赖同位材料资料。 |

## 莫高窟第 85 窟图解术语对照

敦煌研究院与 Getty 在第 85 窟（晚唐）建立了中英双语的图解术语，每条有项目定义和正光／侧光成对、带比例尺的图例（附录 12.C，印刷页 361–376）。术语按层位组织，适合把逐区判断从“可见形态”收窄到“哪一层出了问题”。该术语是针对 85 窟晚唐制作工艺和具体病害制定的，用于其他洞窟或遗址时需按对象调整。

### 层位结构

由内向外依次为：沙砾岩（崖体）→ 粗泥层 → 细泥层（粗泥层和细泥层合称地仗）→ 底色层（粉层）→ 画层 → 局部表面涂层。照片上判断缺损深度，主要看露出面属于哪一层：露出浅色、平滑的底色时多为画层脱落；露出土黄或灰褐、带草筋或细颗粒的泥面时多为粉层脱落；露出粗粒、卵石状砾石时为地仗脱落。三者的色调可能因洞窟、工艺和光照接近，需要比例尺近摄和侧光确认台阶关系。

### 术语与照片判读

| 层位 | 术语（85 窟定义） | 照片上可见的线索 | 容易混淆与补证 | 单图证据级别 |
|---|---|---|---|---|
| 整体 | 地仗脱落 deep loss：壁画所有结构层脱落，露出沙砾岩 | 露出粗糙砾石面，边缘可见多层断面台阶，与周边画面落差明显 | 深色旧补、阴影。确认露出面为岩体需近摄或现场 | A（形态）／B（层位） |
| 地仗层 | 空鼓 plaster detachment：粗泥层与沙砾岩之间粘结力丧失 | 多数无可见表征；有时见局部隆起、弧形或环形裂缝、边缘错台 | 85 窟以轻敲听声为最可靠的探测与圈定方法，无损仪器均未完全成功。照片只能记“疑似形变”，不能圈定空鼓范围 | C |
| 地仗层 | 严重空鼓 unstable plaster detachment（又称优先处理空鼓）：空鼓部位地仗已丧失整体内聚力，常伴严重裂缝和变形 | 侧光下明显鼓胀、错位、网状或放射状开裂，局部可能已塌落 | 与旧加固的支顶痕迹、不平整原始地仗区分。存在整层坠落风险，核查优先级应为高 | B |
| 整体 | 裂缝 cracks：穿过壁画结构中任何一层或所有层的裂隙 | 线状中断，可跨越纹样；侧光下可见缝宽和两侧高差 | 85 窟部分裂缝在地仗干燥时已形成，之后才上彩，表现为颜料覆盖或填入缝中，不一定是后期损伤。对照线描、接缝和拼接伪影 | A（形态）／B（是否在绘前形成） |
| 整体 | 机械损伤 mechanical damage：无意或有意（如刻画涂写）造成的物理损伤 | 方向一致、边缘锐利的划痕，刻写字迹，撞击形成的缺口 | 原有刻线、题记、起稿线。85 窟主室此类损伤局部且少；甬道等曾暴露区域还见风沙磨蚀 | A |
| 整体 | 酥碱 disruption：通常与盐相关，任何一层或多层内部内聚力部分丧失 | 表面粗糙、起砂、颗粒化，画面细节模糊，侧光下呈凹凸不平的颗粒纹理 | 与积尘、白色沉积、原始粗糙地仗区分。是否与可溶盐有关需盐分检测和环境资料 | C |
| 地仗层 | 火山口状鼓起与脱落 crater eruption & loss：画层、底色层和细泥层小范围起鼓（直径约 0.5–1 cm）导致火山口状脱落，脱落处留有硫酸钙硬核 | 成片散布的小圆坑或圆形鼓包，坑底中心常见浅色硬粒，边缘呈环状 | 与点状脱落（更小、无中心硬核）、装饰圆点、气泡区分。硬核成分需取样分析 | B |
| 地仗层 | 酥碱起甲 exfoliation：画层、底色层和部分细泥一起起翘，与其下地仗失去内聚力相关 | 起翘的薄片背面带有泥层，比单纯起甲更厚、更粗糙；侧光下边缘阴影明显 | 与起甲（只涉及底色层或画层）区分，关键看翘起片是否带泥。85 窟主要出现在主室西端 | B |
| 粉层 | 粉层脱落 ground loss：底色层与画层一并脱落 | 露出土黄或灰褐泥面，周边保留浅色底色，边界常呈片状 | 与画层脱落区分，看露出面是浅色平滑底色还是泥面。85 窟记录时反向圈画“残存粉层” | B |
| 粉层 | 点状脱落 punctate loss：画层和底色层直径小于 1 mm 的圆形脱落 | 密集的细小白点或浅点，严重时连成片 | 与颜料颗粒、霉斑、喷溅和图像噪点区分，需要高倍近摄。85 窟集中在主室西端墙基和有附着泥层的部位，最严重时导致画层与底色层全部脱落 | B |
| 画层 | 画层脱落 paint loss：画层脱落露出下方底色层 | 色块内出现浅色斑，线描中断，下方底色平滑完整 | 与原画留白、浅色设色、旧补色区分。85 窟记录时反向圈画“残存画层” | A（形态）／B（层位） |
| 画层 | 起甲 flaking：底色层、画层或表面涂层起翘并伴有破损 | 鳞片状翘起，边缘破碎；侧光下鳞片边缘有亮暗交替 | 与酥碱起甲（翘片带泥）和泡状起甲（闭合鼓泡）区分。正光下常难辨，须侧光 | B |
| 画层 | 泡状起甲 blistering：底色层、画层或表面涂层气泡状变形并脱离，最终导致脱落 | 闭合的圆顶状或条带状隆起，破裂后留下边缘卷起的缺口 | 主要见于窟顶。正光下几乎看不出，图例均用侧光拍摄。由此造成的缺失应单独记为“泡状起甲脱落” | B（有侧光）／C（仅正光） |
| 画层 | 颜料变色／色料褪色 pigment alteration / colorant fading：矿物颜料变化或有机色料褪色 | 原本应同色的纹样出现蓝绿、红黑等差异；局部发黑的圆点或色块；色彩整体变淡 | 85 窟所见例子：蓝色横带在东坡仍为蓝，在西坡呈绿色，被解释为石青转变为绿色氯化铜类颜料；有机色料褪色由入口向内呈梯度，与历史上崖面坍塌后入口长期受光相关。单图须与对称或同类纹样对照，并排除白平衡影响 | B（有对照）／C（无对照） |
| 表面沉积 | 昆虫排泄物 insect excreta：昆虫的黑色有光泽排泄物 | 黑色小点或短流痕，表面有光泽，常成簇分布 | 与霉斑、烟熏、颜料变黑区分；光泽和凸起感是关键，需正光与侧光对照 | B |

### 85 窟调查给照片判读的提示

85 窟的病害分为两大类。一类是深层病害，包括空鼓、地仗裂缝和酥碱；另一类是表层及次表层病害，包括起甲、泡状起甲、酥碱起甲、点状脱落、火山口状脱落和变色。两类病害都由窟口东南向西北加重，以主室西北角最为严重；西壁约 70% 的地仗已与岩体分离。这种分布模式结合盐分调查和环境监测，被用来推断可溶盐与相对湿度的共同作用。

在单张照片中，可以把空间分布当作辅助证据，例如同一墙面上起甲、点状脱落向墙基或窟内方向加重。但分布规律不能代替本对象的盐分和湿度资料，也不能外推到其他洞窟。

85 窟的记录做法可以用来提出补拍要求：相机垂直于墙面，固定距离 140 cm，每幅覆盖 85 × 110 cm，相邻幅重叠约 30%，画面内放灰卡和色标，并标注日期、墙面方位和分区编号；病害图例一律成对拍摄正光和侧光。在评估中提出补证建议时，可以要求按这一规格补拍同一位置。

## 从形态到逐点判断

- 片斑跨纹但缺少层阶时，写出最能解释中断的表层缺失或覆盖倾向，并列出旧填补。只有见到平滑残底、底层断阶或明确支撑体且有对照时，才把解释收窄到相应层位。
- 把细线的连续性、分叉、端点和是否跨原纹样写入证据。疑似裂隙需与擦划、描线、接缝及影像拼接区分。规则尖瓣、圆点及同心图案可用相邻同类纹样作对照。
- 每条解释给一项能改变判读结果的核查。例如用换向侧光核对斑块的凸起或凹缺；用未经拼接的原幅核对方正接缝；用可比时间序列判断变化。优先用可定位的非接触摄影和既有档案，现场进一步检测由负责的文保人员决定。
- 逐条分别记录诊断置信度和核查优先级。置信度仅反映写下的解释或形态；单张照片没有足够证据时，活动性写未评估。不可因病害名称在其他对象中风险高而提高本对象的置信度。
