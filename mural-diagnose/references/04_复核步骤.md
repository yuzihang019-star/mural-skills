# 第二阶段：逐条复核（02_review.json）

读取同一案例的 `case_meta.json`、`01_candidates.json` 和 `01_findings.json`，查阅初筛的影像质量说明、疑似现象及排除依据。逐条鉴别前查阅 [病害百科](01_病害百科.md) 中与候选相关的形态、层位和鉴别要点，并优先采用项目已提供的术语和调查范围。

## 核对与判断

1. 先看原图或适当缩小的整图，定位观察范围、遮挡、反光、裁切和分辨率限制。再按需要分批看候选局部和周围上下文。比较与原有线描、重复纹样、色差、反光或采集痕迹的关系。
2. 对每个初筛候选保留编号和坐标。根据候选实际提出的判断选择 `确认`、`存疑` 或 `否决`。例如，照片清楚显示浅斑边界，是否丢失了颜料或底色仍待核查。在 `evidence` 写清判断依据及仍成立的其他解释，在 `type` 写暂定类型或「待定」。病害成因、活动性、材料或结构状态须结合相应检查。
3. 从复核候选中保留与评估目的有关的现象。可新增影像上可见但未由初筛定位的区域，也可合并同类相邻表现，记录定位框和实际分布。按后续跟踪或核查的需要排序。用 `A`、`B` … `Z`、`AA` 等唯一标签。修改边界时沿用同一现象的标签。
4. 在 `overall_observation` 说明实际可评范围、可见的总体状况和限制。可评范围内未见明显异常时，记录该范围和分辨能力。影像不足以判断时，说明哪些区域或问题无法评估、补什么资料。两种情况都可保留空的 `regions`。

## 区域字段

| 字段 | 内容 |
|---|---|
| `label`、`bbox_xywh`、`from_candidate` | 唯一标签、原图整数像素框 `[x,y,w,h]`、对应初筛候选编号。新增区域填 `null` |
| `map_marks` | 可选，沿原图证据标出的点、线或范围。位置框仍保留，见下节。 |
| `phenomenon`、`evidence`、`type` | 简要说明部位和现象，记录支持判断的具体图像特征，再填写暂定类型。 |
| `impact`、`confidence` | 对画面、材料记录或复查的可见影响和判断置信度。 |
| `needs_onsite` | 尚待解决的问题与核查方式，例如查对原始图像、补拍、现场检查。 |
| `diagnosis` | 病害判断和人工核查方法，见下表。新写的区域填全六项，既有无此字段的案例仍可读取。 |

| `diagnosis` 字段 | 内容 |
|---|---|
| `primary` | 照片最支持的判断。能辨认脱落样外观且分不出层位时写「疑似局部表层脱落，涉及的层位待核查」。只能辨认颜色或形状时保留现象。 |
| `reason` | 写使这一判断更可能的图像特征，例如「不规则褐斑中断眉线，斑缘外的眉线仍连贯」。 |
| `alternative` | 写本处仍可能成立的其他解释和关键证据缺口。 |
| `verification` | 写查哪一处、用什么方法、看什么差异。 |
| `confidence` | 对 `primary` 的置信度，高／中／低。面向读者的「照片依据」依次显示较清楚／有限／较弱。 |
| `priority` | 后续核查优先级，优先／常规／随访。 |

## 面向读者的写法

1. **可见现象**取 `phenomenon` 与 `evidence`，按部位、所见形态及受影响纹样连成一段。同一句信息出现一次即可。
2. **病害判断**依次列 `diagnosis.primary`、`reason` 和 `alternative` 中本处最有区分力的信息。照片依据与核查优先级单独显示，均不能用于表示病害严重程度。
3. **人工核查方法**以 `diagnosis.verification` 为准，`needs_onsite` 只补不同的信息。
4. **保护措施**由 `mural-conserve` 补写。照片证据、现场结论和拟采取的措施分别保留。

例如，眉线上一块黄褐斑可以写「图像右侧眉线上有一块不规则黄褐斑，原有绿线到斑缘处中断」。判断可写「疑似表层局部脱落，也可能是附着物覆盖眉线」。人工核查可写「双向斜光近拍这块斑，看边缘是否有凹下的台阶，或有高出画面的附着物。对照现场同位照片检查绿线能否在斑下辨认」。

横穿腹部圆饰的褐色细线，可写「细线越过圆饰边缘和几个人物线条，中间有一段看不清」。病害判断写「疑似裂隙，也可能是擦划或旧修留下的接痕」。人工核查写「沿外侧褐带、圆饰交界和内部细线分段补拍带比例尺的正面与双向斜光近照。检查有没有连续开口或两侧高差，核对几段线是否接在一起」。

灰绿头光里的浅白小点若只看清颜色和分布，可写「灰绿色底上有一小簇浅白点」。病害判断写「白点性质待查」。人工核查写「带比例尺近拍白点和邻近完好表面，观察白点是贴在表面、嵌在颜色内，还是凹下的小缺口。需鉴别成分时由文保人员选择无损检查或安排取样」。

成因、活动性和实际层位限于已有调查资料能支持的范围。`check_review.py` 会提醒检查「确诊」「肯定是」等绝对化措辞。

## 可选的图上标记

`bbox_xywh` 一直用于定位和裁图。`map_marks` 可以附在任意区域上。有足够证据时，沿原图标一点、一道线或可辨认的外边界。一个区域有多个独立点时分别写入。没有清楚边界的色差或点簇可以保留定位框。

```json
{
  "bbox_xywh": [420, 250, 150, 120],
  "map_marks": [
    {"kind": "point", "points": [[438, 281]]},
    {"kind": "line", "points": [[455, 300], [481, 311], [511, 326]], "tentative": true},
    {"kind": "polygon", "points": [[522, 275], [540, 280], [551, 298], [526, 296]]}
  ]
}
```

坐标为基准照片中的整数像素。每点位于原图和区域框内，右侧和底部的外边界不在框内。点只写一个坐标，线至少两个，面至少三个并自动闭合。可选的布尔值 `tentative` 表示位置或外缘尚待核对，省略时按已描记的可见范围处理。它不表示病害诊断已经确认。未在照片上辨认出的范围留空，方框不能直接转成病害面。没有 `map_marks` 或写 `[]` 时，`02_regions.png` 继续显示定位框。有标记时显示点、线或轮廓，存疑的点用空心点，线和轮廓用虚线。

## 参照案例

- 莫高窟 196 窟研究的图 5-1 用局部照片说明不同病害。按实物统计面积和裂隙长度，以及通过样品判断盐分，是另有现场依据的步骤。[张亚旭《莫高窟196窟壁画保存现状研究》，§5.1–5.2](https://ygx.sxu.edu.cn/db/%E5%AD%A6%E4%BD%8D/D01599490.pdf)
- 赤峰馆藏壁画病害图在照片底图上区分点、线和范围，并附图例、调查信息和实物比例尺。影像上看不清边缘时保留定位框，尺度未经核定时使用原图像素。[任亚云论文，第 387 页图 10](https://www.cactch.org.cn/webfile/upload/2020/12-21/16-02-1506531069831926.pdf#page=7)
- 故宫如亭的图 2 展示病害局部照，图 5 用形变条纹核查普通照片难辨的浅表和亚表面异常。图 7 的高光谱图用于增强图纹。对具体对象应先指出待区分的现象，再由文保人员决定适用方法。[故宫博物院《如亭壁画检测分析》，图 2、5、7](https://www.dpm.org.cn/ydyl/demonstration/detail/262833.html)

## 交接

校验通过后生成 `02_regions.png` 并写入 `workflow_log.jsonl`。`02_review.json` 保留候选结论、关注区域、专业判读和评估范围，供 `mural-conserve` 读取。
