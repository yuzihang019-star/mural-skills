# ② AI 视觉复核（mural-review）

```
① 初筛 →【② AI 复核】→ ③ 建议 → ④ 人工复核 → ⑤ 观察卡
```

① 已经按识别手册看过一遍图，给出了带类型、证据、信心的疑似病害（`01_candidates.json`，同时保留了 ① 排除的误报 `rejected`）。这一步是“第二双眼睛”：用新的视角逐个复核这些候选，补上漏检，最后挑出 1–3 处最值得关注的区域，写成观察卡能直接用的说明。复核时可以翻看 mural-screen 的 `references/01_病害百科.md`。这里的所有结论都标记为“AI 生成”，要等到 ④ 由队员人工复核。

## 步骤

1. 生成模板：
   ```bash
   python <skill>/scripts/init_review.py <案例文件夹> --model "<你的模型名称，如 Claude Opus 5.5>"
   ```

2. 看图。**控制上下文：每次只读一张缩小过的图，整个复核读图不超过 4–5 次。**
   - 先读 `01_crops.png`（所有候选的局部拼图，一次看完）。
   - 再生成并读全图（带坐标网格，便于给新增区域写坐标）：
     `python <skill>/scripts/view.py <案例> whole`
   - 需要放大确认某处时：`python <skill>/scripts/view.py <案例> box x,y,w,h [x,y,w,h ...]`，多个框一次拼成一张。
   - 不要直接读原图大文件。

3. 填写 `02_review.json`：
   - `overall_observation`：1–2 句整体观察（画面内容、整体保存状况）。
   - `candidates[]`：每个候选都要填 `verdict`（确认/存疑/否决）、`type`、`evidence`、`confidence`（高/中/低）。否决也要写原因，比如“原有衣纹线描，非病害”。
   - `regions[]`：最终的 1–3 处关注区域，标签依次为 A、B、C。可以来自候选（填 `from_candidate`），也可以是模型漏检、你新增的（`from_candidate: null`，坐标按原图像素）。每处填：
     - `phenomenon`：一句话现象，例如“人物衣袖处颜料成片缺失，露出浅黄色底层”。
     - `type`：疑似病害名称，加“疑似”。
     - `evidence`：只写图里真实看得到的颜色、形状、边界、与周边关系。
     - `impact`：对画面内容的影响，例如“遮挡了人物手部轮廓，影响姿态辨识”。
     - `confidence`：高/中/低。
     - `needs_onsite`：仅凭图像无法确认、需要现场或侧光核查的点。

4. 校验并出图：
   ```bash
   python <skill>/scripts/check_review.py <案例文件夹>
   ```
   不通过会列出缺项；通过后生成 `02_regions.png`（A/B/C 三色框），并写入工作日志。

5. 向用户简要汇报选了哪几处、为什么，然后提示进入 ③ `mural-advise`。

## 选区原则

优先选：对画面内容影响大的（人物面部、手部、题记、主要纹样）；证据清楚的；类型各不相同的（比如一处脱落、一处裂隙、一处污染），这样观察卡信息量更大。

画面整体保存很好、找不到明显问题时，可以只选 1 处，并如实写“未见明显病害，此处为最值得关注的轻微现象”。不要为了凑数编造问题。

## 常见误判

把这些当成病害是最常见的错误：高对比度的原有纹样（衣纹、云纹、线描、晕染）、颜料本身的浅色（白粉、土黄、石绿褪色前后的自然色差）、画面边缘和裁切边、拍摄反光和阴影、图像压缩块。

## 病害术语（参照 GB/T 30237-2013《古代壁画病害与图示》，以标准原文为准）

| 仅凭图像可以初判 | 必须现场 / 侧光 / 取样才能确认 |
|---|---|
| 颜料层脱落、地仗脱落、点状脱落、裂隙、龟裂、划痕、涂写、水渍、烟熏、污染、褪色/变色、霉斑（疑似） | 起甲、粉化、酥碱、盐霜、空鼓、疱疹 |

右栏的病害即使在图像上像，也只能写“疑似”，并在 `needs_onsite` 说明需要什么核查。

## 诚实要求

`evidence` 里不许出现你没在图里看到的东西，也不许写历史年代、洞窟编号等图里没有依据的信息，除非用户提供了资料。拿不准就写“存疑”和“低”。
