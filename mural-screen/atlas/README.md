# 对照图册（atlas）

用 MuralDH 数据集（敦煌壁画，CC0）`Mural_seg/train` 里**人工标注过的**图片自动裁出来的对照图。看图时拿不准“这是不是病害”，翻这里对照。

**黄线 = 数据集标注的病害边界；红框 = 小模型认为“可能有病害”的地方。**

| 图 | 内容 | 用途 |
|---|---|---|
| `A_标注病害_按形态.jpg` | 真实标注的病害，按形状分：dots 点状、patch 片状、large 大面积、line 线状 | 看“真的脱落长什么样”：边缘硬、颜色突然变浅、切断原画线条 |
| `B_小模型误报.jpg` | 小模型标了、但标注说**不是**病害的地方 | 看“最容易被当成病害的正常画面” |
| `C_小模型漏检.jpg` | 标注是病害、小模型却没发现的地方 | 看“哪些病害容易漏”，自己看图时要多留意 |

## 从图册里能学到的几点

1. **浅色 ≠ 脱落。** B 图里大部分误报是人物白净的脸、白色衣饰、珠串、团花这类**原画就是浅色**的地方。分辨办法：原画浅色区边缘跟着轮廓线走、形状规整、有重复的纹样；脱落的边缘像被啃过，还会切断线条。
2. **规则重复的白点多半是装饰**（珠串、点饰），不是点状脱落。
3. **线状病害容易漏**（A 图 line 组、C 图）：细长的白色缺口很窄，整图缩小后几乎看不见，必须在分块放大图里找。
4. **标注本身不完美。** 数据集只标了明显的缺失；有些污渍、变色、轻微磨损没标（例如 B1 的浅色区域可能有污染）。图册说明的是“标注者认为的病害”，不等于最终结论。

## 注意

- 数据集**只有“有/无病害”两类，没有病害类型**。A 图的分组只是按形状分的，不是病害名称。
- 图册随机抽了 160 张训练图，用 `scripts/build_atlas.py` 生成，可以重跑（`--seed` 换一批例子）：
  ```bash
  python <skill>/scripts/build_atlas.py <MuralDH/Mural_seg> <skill>/atlas --n 160 --seed 1
  ```
- 每张原图的文件名和框坐标记在 `atlas.json` 里，需要时可以回原图查看。
- 读图次数有限，**一次只读一张图册**，按需要选 B 或 C，不必每次都看。
