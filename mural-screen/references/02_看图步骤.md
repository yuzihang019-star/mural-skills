# 看图步骤（固定顺序，不要跳步）

大模型看壁画最常见的三个毛病：只看整体、漏掉小病害；把原画的线条当裂缝；没把握也说得很肯定。下面的步骤就是针对这三个毛病设计的。

## 第 1 步：看整体（读 1 张图）

读 `01a_whole.png`（整图缩小 + 坐标网格 + 分块编号）。只回答：
1. 画的是什么（人物、佛像、飞天、建筑、纹样……）、哪些是重要部位（脸、手、题记）。
2. 整体保存状况：好 / 一般 / 差，一句话理由。
3. 有没有明显的大面积问题（大片脱落、大片熏黑、大裂缝）——先记下位置，后面细看。
4. 拍摄情况：有没有反光、阴影、模糊、过度压缩。这些地方后面不下结论。

## 第 2 步：分块放大看（读 1–2 张图）

读 `01b_tiles.png`（把图切成 2×2 或 3×3 块，每块单独放大，带块号和原图坐标）。
**每一块都要看**，并在心里过一遍下面的检查表。小病害（点状脱落、细裂缝、小霉斑）只有在这一步才看得到。

需要时读 `01c_enhanced.png`（对比度增强版）：增强后脱落边缘、细裂缝、浅色覆盖物更明显。**增强版只用来"找"，判断颜色时要回到原图**，因为增强会改变颜色。

## 第 3 步：逐项过检查表

对每一块，依次问：

| # | 问题 | 对应病害 |
|---|---|---|
| 1 | 有没有颜色突然变浅、边缘不规则、切断原画线条的区域？ | 颜料层脱落 |
| 2 | 有没有露出土色、颗粒、草筋，或比周围"深一层"的坑？ | 地仗脱落 |
| 3 | 有没有散布的浅色小点？ | 点状脱落（先排除噪点和原画装饰） |
| 4 | 有没有鳞片状、边缘带亮边/暗影的区域？ | 疑似起甲 |
| 5 | 有没有不理会画面内容、锯齿状的深色线？ | 裂隙（先排除墨线） |
| 6 | 有没有一片网状小格子？ | 龟裂 |
| 7 | 有没有白色、粉状、毛茸茸的覆盖？ | 疑似盐霜 / 酥碱 |
| 8 | 有没有黑褐色渐变覆盖、或上下流淌痕？ | 烟熏 / 水渍 |
| 9 | 有没有黑/绿/灰色成簇斑点？ | 疑似霉斑 |
| 10 | 有没有笔直的划线、后人写的字？ | 划痕 / 涂写 |
| 11 | 同一种颜色是否深浅不一？ | 可能褪色（照片不可靠） |

拿不准是什么病害时，查 `01_病害百科.md` 对应条目；拿不准是不是病害时，查百科第七节"误报清单"，再看 `atlas/` 里的对照图（`B_小模型误报.jpg` 是“像病害但不是”的例子，`C_小模型漏检.jpg` 是容易漏看的病害；说明见 `atlas/README.md`。对照图也算一次读图，按需读一张即可）。

## 第 4 步：放大确认（读 1 张图）

把所有疑似位置一次性放大：
```bash
python <skill>/scripts/look.py <案例> zoom x,y,w,h x,y,w,h ...
```
读生成的 `01d_zoom.png`，逐个确认。坐标统一用**原图像素**。

## 第 5 步：（可选）参考小模型提示

`01_hints.json` / `01_hints.png` 是离线小模型给的"可能有脱落"的位置。它只认识脱落类，而且大约四分之三的提示不在真正的病害上。用法：
- 小模型提示了、你没发现的位置 → **回去再看一眼**，确实有就加上，没有就放进"排除"列表并写理由；
- **不要**因为小模型提示了就认定是病害。

## 第 6 步：写结果并自查

按 `03_输出格式.md` 写 `01_findings.json`，然后对每一条发现问自己四个问题：
1. **证据是我在图里真看到的吗？** 不能写图里没有的东西（年代、洞窟号、材料成分）。
2. **我排除了最容易混淆的那个"正常现象"吗？** 在 `alternatives` 里写出来。
3. **这种病害照片能确认吗？** 百科里是 B、C 级的，信心不能是"高"，必须写 `how_to_verify`。
4. **框画得对吗？** 框住病害本身，留一点边，别把半幅画框进去。

最后运行检查脚本：
```bash
python <skill>/scripts/check_findings.py <案例>
```
脚本会查格式、查"C 级病害标了高信心"这类问题、把结果画成 `01_findings.png`，并整理成下一步 ② 要用的 `01_candidates.json`。

## 读图次数上限

整个流程读图 **不超过 5 次**（整体 1、分块 1–2、放大 1、检查结果 1）。不要直接读原图大文件，会撑爆上下文。

## 没发现病害怎么办

如实写。`findings` 可以是空的，`overall.condition` 写"好"，并说明检查了哪些块。**不要为了凑数编造病害**——比赛评审更看重诚实标注不确定性。
