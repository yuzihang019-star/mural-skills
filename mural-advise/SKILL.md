# ③ 建议与风险（mural-advise）

```
① 初筛 → ② AI 复核 →【③ 建议】→ ④ 人工复核 → ⑤ 观察卡
```

把 ② 的观察变成“可以做什么”。比赛要求：1–2 条保护、数字展示或公众传播建议，说明依据和可能风险。同时把整张卡的不确定性和人工复核点集中写在这里。

## 步骤

1. `python <skill>/scripts/init_advice.py <案例文件夹> --model "<模型名称>"`
2. 读 `02_review.json`（不需要再看图，除非建议涉及某个细节），填写 `03_advice.json`：

| 字段 | 写什么 |
|---|---|
| `suggestions[]` | 1–2 条。`category` 取 保护 / 数字展示 / 公众传播；`title` 一句话；`content` 具体做法；`basis` 依据（引用区域 A/B/C 的哪条观察，加上原则或资料）；`related_regions`；`risk` 可能风险及规避办法 |
| `uncertainty[]` | 整张卡的不确定性：仅凭单张图像、光照和分辨率限制、模型的已知能力边界、哪些判断置信度低 |
| `human_check_points[]` | 具体到“谁、核对什么”：例如“由队员对照高清原图确认 B 处是否为原有线描”“需专业人员现场侧光核查 A 处是否起甲” |
| `references[]` | 用到的公开资料，格式 `{"name": ..., "note": ...}`。只写真实存在、确实参考过的；用户提供的背景资料也写进来 |

3. `python <skill>/scripts/check_advice.py <案例文件夹>`，处理报错和提醒。
4. 向用户简述两条建议，提示进入 ④ `mural-human-check`。

## 三类建议怎么写

**保护**：只写监测、记录、环境控制、提请专业评估这类非干预性措施。比如“对 A 处脱落边缘建立定期拍照监测，比较边缘是否扩展”。不要建议任何实体操作（加固、回贴、清洗），这些必须由文保专业人员现场决定。

**数字展示**：比如“修复前后对比滑块”“病害标注图层可开关”“高清局部放大导览”。依据写清楚为什么这处适合展示；风险写观众可能把虚拟复原当成原貌，需要明确标注“数字参考方案，非原貌”。

**公众传播**：比如“以 C 处为例做一张‘壁画为什么会脱落’的科普图”。风险写简化表达可能失真、宗教和民族题材需审慎表述、未授权高清图不能外传。

## 可以引用的原则（写名称即可，以原文为准，不要编造条款号或原句）

最小干预、可识别、可逆，这几条是文物保护领域公认的原则，见《中国文物古迹保护准则》（2015 年修订版）。病害术语参照 GB/T 30237-2013《古代壁画病害与图示》。虚拟修复要和原物、原图明确区分，不能无依据补全缺失内容，这一点也是赛题规则里明确提出的风险。

## 风险写法要具体

不好的写法：“可能存在误差”。

好的写法：“B 处可能是原有晕染而非褪色；若误判并在数字展示中‘补色’，会改变原画色彩关系。规避：展示时保留原图图层，补色区域单独标注。”
